## Platform

web

## Users

Primary audience confirmed by the user: young students arriving in Nueva Córdoba from across Argentina, often alone, to study. Local residents, professionals, group organizers and businesses also use the existing directory.

## Product Purpose

Help neighbors find local places, services, groups and connections. The user approved implementing plans, study companions, newcomer guidance, student-budget resources, origin/interest connections and student exchange.

## Capabilities and Constraints

Existing Next.js/Prisma/PostgreSQL catalog and Cloudinary media. Preserve existing UI work and catalog data. New community content needs persistent ownership, moderation and explicit contact choices. Real event attendance, discounts and identity verification must not be invented.

## Brand Commitments

Existing name, logo and Argentine Spanish voice are retained. This implementation extends the current interface.

## Evidence on Hand

Local brand assets/photos in public; existing places/professionals/groups in the catalog. No confirmed event schedule, participating merchants or community listings supplied. Start with useful guides and honest empty states.

## Open Decisions

Moderators and real launch content have not been designated. Deployment is not requested. Admin bootstrap will be documented without default credentials.
